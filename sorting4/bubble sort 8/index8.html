Bubble Sort Visualization

Bubble Sort is a simple sorting algorithm that repeatedly steps through the list, compares adjacent elements and swaps them if they are in the wrong order.
Best Case: O(n)   |   Average Case: O(n2)   |   Worst Case: O(n2)

Code Logic



function bubbleSort(arr) { let n = arr.length; for (let i = 0; i < n - 1; i++) { for (let j = 0; j < n - i - 1; j++) { if (arr[j] > arr[j + 1]) { [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]]; } } } return arr; }

Algorithm Explanation

Bubble sort works by repeatedly swapping the adjacent elements if they are in the wrong order. This process continues until no more swaps are needed, indicating the array is sorted. It's called "bubble" sort because smaller elements "bubble" to the top of the list.
