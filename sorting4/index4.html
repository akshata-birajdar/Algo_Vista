Sorting Algorithms

Sorting is the process of arranging elements in a specific order, typically in ascending or descending order.
It is a fundamental operation in computer science used to organize data efficiently for searching, processing, and analysis.

Available Sorting Algorithms

Bubble Sort

Repeatedly compares adjacent elements and swaps them if they are in the wrong order.

Visualize

Selection Sort

Finds the smallest element and swaps it with the first unsorted element.

Insertion Sort

Builds the sorted array one item at a time by inserting elements in the correct position.

Merge Sort

Uses the divide-and-conquer technique to split and merge sorted arrays.

Quick Sort

Partitions the array around a pivot and sorts the subarrays recursively.
