Sorting Algorithms

Time Complexity

Best Case (Sorted List): O(n)

Average Case: O(n²)

Worst Case (Reversed List): O(n²)

Space Complexity

O(1) (In-place sorting algorithm, no extra memory required)

Bubble Sort

Bubble Sort is a simple sorting algorithm that repeatedly steps through the list,

compares adjacent elements, and swaps them if they are in the wrong order.


for i = 1 to (n - 1):
    swapped = false
    for j = 1 to (n - i):
        if arr[j] < arr[j + 1]:
            swap(j, j + 1)
            swapped = true
    if not swapped:
        break
