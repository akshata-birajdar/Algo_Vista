Insertion Sort Visualization

Insertion sort places an unsorted element at its correct position in each iteration.


for i = 1 to (n-1):
  key = arr[i]
  j = i - 1
  while j >= 0 and arr[j] > key:
    arr[j + 1] = arr[j]
    j = j - 1
  arr[j + 1] = key
