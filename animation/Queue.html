📚 Queue Evaluation Visualizer

Queues follow the FIFO (First In First Out) principle. Use enqueue to add elements and dequeue to remove them in order.
queue = []
enqueue(value):
    queue.append(value)
dequeue():
    if queue is not empty:
        queue.pop(0)
