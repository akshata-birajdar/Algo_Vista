🧱 Stack Operation Visualizer

Stacks follow the LIFO (Last In First Out) principle. Push elements to add to the top, and pop to remove the topmost element.

stack = []
push(value):
    stack.append(value)
pop():
    if stack is not empty:
        stack.pop()
